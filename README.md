# appleseed ホームページ

## 構成・確認方法

HTML・CSS・JavaScriptで構成した静的サイトです。ビルド処理は不要です。原本はこの `appleseed` フォルダです。

- `index.html`：トップ。各詳細ページへの入口
- `services.html`：サービス・制作の流れ
- `works.html`：制作実績（現在は未掲載）
- `pricing.html`：料金
- `about.html`：会社概要・事業者情報
- `contact.html`：お問い合わせ・メール作成フォーム
- `news.html`：ブログ・お知らせの掲載先（現在は記事なし）
- `assets/css/style.css`：全ページ共通のデザイン
- `assets/js/main.js`：メニュー、旧ページ内リンクの移行、問い合わせ入力確認

ブラウザで `index.html` を開いて確認できます。プロジェクトのルートでローカルサーバーを起動している場合は `/appleseed/` がトップページです。旧トップの `#services`・`#works`・`#price`・`#about`・`#contact`・`#news`・`#flow` はJavaScriptで対応する新ページへ案内します。

## 更新・公開

管理者が対象HTMLファイルを編集し、公開先へ再アップロードします。共通ヘッダー・フッターを変更する際は全7ページに反映してください。

お知らせを追加する場合は `news.html` の空表示を記事一覧に置き換え、確認済みのタイトル・公開日・本文を掲載します。必要に応じて記事HTMLを作り、トップページのお知らせ欄も更新します。管理画面・CMS・ブラウザからの保存機能は未導入です。

公開時は7つのHTMLと `assets` フォルダを同じ階層のまま公開フォルダへ配置してください。READMEとプロジェクトルートのAGENTS.mdは公開対象ではありません。公開先・ドメインは未確定です。現在はローカルのみで、公開済みではありません。

## 問い合わせフォーム

入力 → 内容確認 → メールアプリを開く → 訪問者自身が送信する方式です。内容確認では送信されません。入力内容はサーバーやブラウザの保存領域へ保存しません。メールアプリが設定されていない場合に備え、本文のコピーと連絡先も表示します。

サーバーから直接メールを送る処理、送信完了判定、受信確認は未導入です。実際のメール送受信は未検証です。直接送信への変更は公開先と送信サービスの確認後に行います。
